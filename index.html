About the project

Understand patterns. Explore risk. Ask better questions.

This project presents a visual exploration of healthcare data using Tableau Public. The dashboard organizes selected patient and lifestyle indicators into charts, while the story view guides visitors through the visualizations in a sequence.

It is intended for learning and exploratory analysis—not for diagnosis, individual medical advice, or proving that one factor causes a health outcome.
